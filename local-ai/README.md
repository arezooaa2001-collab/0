# 🤖 هوش مصنوعی من (Local AI Studio)

چت، ساخت عکس، ساخت ویدیو و ساخت آهنگ — **همه روی کامپیوتر خودت**.

- ❌ بدون کلید API
- ❌ بدون حساب کاربری و بدون پرداخت
- ❌ بدون نیاز به GitHub یا Claude برای اجرا
- ✅ بعد از دانلود اولیه مدل‌ها، کاملاً **آفلاین** کار می‌کند
- ✅ رابط فارسی زیبا (`studio.html`)، داخل مرورگر خودت (`http://127.0.0.1:7860`)
- ✅ متن فارسی را خودش به انگلیسی دقیق ترجمه می‌کند تا عکس/ویدیو/آهنگ طبیعی‌تر شود

| بخش | مدل متن‌باز | توضیح |
|---|---|---|
| 💬 چت | Qwen 2.5 (7B) از طریق Ollama | فارسی را خوب می‌فهمد و طبیعی جواب می‌دهد |
| 🖼️ عکس | RealVisXL V4 (بر پایه SDXL) | مخصوص عکس‌های واقع‌گرا و طبیعی |
| 🎬 ویدیو | Wan 2.1 (1.3B) | ویدیوی ۲ تا ۸ ثانیه‌ای 480p با حرکت طبیعی |
| 🎵 آهنگ | MusicGen Medium از Meta | موسیقی بی‌کلام تا ۳۰ ثانیه |

## سیستم لازم

| | حداقل | پیشنهادی |
|---|---|---|
| کارت گرافیک | NVIDIA با ۸ گیگ VRAM | NVIDIA با ۱۲ گیگ یا بیشتر (مثل RTX 3060 12GB / 4070) |
| رم | ۱۶ گیگ | ۳۲ گیگ |
| فضای خالی | ۴۰ گیگ | ۶۰ گیگ (SSD) |

> بدون کارت NVIDIA هم اجرا می‌شود، ولی ساخت عکس چند دقیقه و ساخت ویدیو چند ساعت طول می‌کشد. چت و آهنگ روی CPU قابل‌استفاده‌اند. مک‌های M1/M2/M3 برای چت، عکس و آهنگ مناسب‌اند.

## نصب روی ویندوز (یک بار)

1. **Python 3.11** را از <https://www.python.org/downloads/> نصب کن — موقع نصب تیک **Add Python to PATH** را بزن.
2. **Ollama** را از <https://ollama.com/download> نصب کن.
3. روی فایل **`install.bat`** دوبار کلیک کن و صبر کن تا تمام شود.

## اجرا

روی **`start.bat`** دوبار کلیک کن. مرورگر خودش صفحهٔ `studio.html` را باز می‌کند (آدرس `http://127.0.0.1:7860`).
رابط ساده‌تر Gradio هم در `http://127.0.0.1:7860/gradio` هست.

### فقط فایل HTML، بدون نصب

اگر `studio.html` را مستقیم (با دوبار کلیک) باز کنی و برنامه نصب نباشد، در **حالت آنلاین رایگان** کار می‌کند:
چت و عکس از سرویس رایگان Pollinations.ai (بدون کلید API) گرفته می‌شود. این حالت به اینترنت نیاز دارد، ممکن است شلوغ یا محدود باشد،
و ویدیو و آهنگ در آن نیست — برای آن‌ها باید برنامه را نصب کنی.

> اولین باری که عکس/ویدیو/آهنگ می‌سازی، مدل آن بخش دانلود می‌شود (حدود ۷ تا ۱۵ گیگ برای هر کدام). دفعه‌های بعد فوری شروع می‌شود و دیگر اینترنت لازم نیست.

## نصب روی لینوکس / مک

```bash
./install.sh
./start.sh
```

## نکته‌ها برای نتیجه طبیعی‌تر

- **دقیق توضیح بده**: نور، زمان روز، مکان، حس و حال. مثلاً «پیرزن خندان کنار پنجره، نور نرم صبح، عکس نزدیک».
- اگر نتیجه‌ای را دوست داشتی، عدد **Seed** آن را نگه دار تا بتوانی شبیهش را دوباره بسازی.
- کیفیت (تعداد مراحل) بیشتر = نتیجه بهتر ولی کندتر.
- فایل‌ها در پوشه `outputs` ذخیره می‌شوند.

## عوض کردن مدل‌ها (اختیاری)

قبل از اجرای `start` می‌توانی مدل دیگری انتخاب کنی:

```bat
set CHAT_MODEL=gemma3:12b
set MUSIC_MODEL=facebook/musicgen-large
start.bat
```

متغیرها: `CHAT_MODEL`، `IMAGE_MODEL`، `VIDEO_MODEL`، `MUSIC_MODEL`.

## محدودیت‌ها (صادقانه)

- آهنگ‌ها **بی‌کلام** هستند؛ MusicGen خواننده ندارد. برای آهنگ با صدای خواننده باید مدل جداگانه‌ای مثل ACE-Step اضافه شود.
- ویدیوها کوتاه (حداکثر ۸ ثانیه) و 480p هستند — این سقف مدل‌های رایگانی است که روی کارت گرافیک معمولی جا می‌شوند.
- هیچ مدل هوش مصنوعی‌ای همیشه ۱۰۰٪ طبیعی نیست؛ گاهی باید چند بار با Seed مختلف امتحان کنی.
