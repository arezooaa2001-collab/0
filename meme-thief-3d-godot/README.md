# دزد میم‌ها ۳بعدی — نسخه‌ی Godot

این پوشه نسخه‌ی **Godot 4** بازی «دزد میم‌ها ۳بعدی» است که از فایل HTML/Three.js اصلی (`original/meme-thief_3.html`) بازنویسی شده است.
همه‌ی کد با GDScript نوشته شده و هیچ فایل مدل یا صدای بیرونی لازم ندارد: میم‌ها، پایگاه‌ها، بافت‌ها، صداها و موسیقی همه هنگام اجرا ساخته می‌شوند، درست مثل نسخه‌ی اصلی.

## اجرا

1. Godot نسخه‌ی **4.3** یا جدیدتر (نسخه‌ی معمولی، نه .NET) را از godotengine.org دانلود کن.
2. در Project Manager دکمه‌ی **Import** را بزن و فایل `project.godot` همین پوشه را انتخاب کن.
3. دکمه‌ی ▶ (F5) را بزن.

برای ساختن فایل اجرایی ویندوز، اندروید یا وب از منوی **Project → Export** استفاده کن (اول باید Export Templates را از همان‌جا دانلود کنی). روی موبایل و وب، رندرر Compatibility خودکار انتخاب می‌شود.

## چه چیزهایی منتقل شده

- هر ۵ دنیا: میدان میم‌ها، سیاره‌ی گدازه، جزیره‌های آسمانی، قطب یخی و ماه نئونی، با پرتال‌ها و خطرهای هر کدام (گدازه، شهاب‌سنگ، باد، صاعقه، یخ لیز، کولاک، گلوله‌برفی، لیزر چرخان، جاذبه‌ی کم)
- بیش از ۱۶ هزار میم: ۴۱ میم دست‌ساز با همان مدل‌ها و انیمیشن‌ها، و میم‌های رویه‌ای با همان مولد قطعی (همان اسم، قیمت و ظاهر)
- نوار نقاله، خرید، درآمد، سکوی جمع‌آوری، سپر لیزری، دزدی، سیلی، نگهبان‌ها، هوش مصنوعی حریف‌ها با مسیریابی A*
- فروشگاه‌ها (شهر، کیوسک‌های پایگاه، فروشگاه هر دنیا)، کمد لباس، پت‌ها، اسکیت‌برد، دستگاه ترکیب، ارتقای ستاره‌ای، خانه‌ی امن با در آهنی و دریل
- رویدادها (باران طلایی، یوفو و…)، رئیس دزدها، صندوق گنج، ماموریت‌ها، دستاوردها، جایزه‌ی روزانه، تولد دوباره، چرخه‌ی روز و شب، آتش‌بازی
- رابط کاربری فارسی و راست‌به‌چپ با فونت وزیرمتن: HUD، نقشه‌ی کوچک، دانشنامه، کلکسیون، تنظیمات، آموزش تعاملی
- کنترل کیبورد و موس، جوی‌استیک و دکمه‌های لمسی، و دسته‌ی بازی
- ذخیره‌ی خودکار روی دستگاه، درآمد زمان غیبت و «کد پیشرفت» (MEME1:…) برای انتقال بین دستگاه‌ها

## تفاوت‌ها با نسخه‌ی HTML

- ذخیره‌ی ابری Claude حذف شده، چون فقط داخل صفحه‌ی Artifact کار می‌کرد. به‌جایش از «کد پیشرفت» در تنظیمات استفاده کن.
- نوشته‌های سه‌بعدی (تابلوها و برچسب اسم میم‌ها) با `Label3D` ساخته می‌شوند و ایموجی‌ها با فونت تک‌رنگ Noto Emoji نمایش داده می‌شوند.
- نورها طوری تنظیم شده‌اند که ظاهر کلی شبیه نسخه‌ی اصلی باشد، ولی رنگ‌ها و سایه‌ها دقیقاً یکسان نیستند.

## کلیدها

`W A S D` حرکت · `Shift` دویدن · `Space` پرش · `E` تعامل و خرید · `F` دزدی · `G` رها کردن · `Q` سپر · `R` سیلی · `H` اسکیت‌برد · `J` ماموریت‌ها · `I` کلکسیون · `K` دانشنامه · `L` جدول · `M` نقشه · `C` دوربین · `O` تمام‌صفحه · `F1` راهنمای کلیدها · `Esc` توقف

## ساختار کد

| پوشه | محتوا |
| --- | --- |
| `scripts/core` | داده‌ها، تنظیمات، صدای رویه‌ای، توابع کمکی |
| `scripts/gfx` | ساخت هندسه و متریال، بافت‌های رویه‌ای، تابلوهای متنی، ذرات |
| `scripts/world` | فیزیک برخورد، مسیریابی، پایگاه‌ها و ساخت هر ۵ دنیا |
| `scripts/chars` | ساخت میم‌ها و آدمک‌ها و انیمیشن آن‌ها |
| `scripts/game` | منطق بازی: صاحبان، میم‌ها، هوش مصنوعی، اقتصاد، ماموریت‌ها، ذخیره |
| `scripts/ui` | تمام رابط کاربری |
| `scripts/main.gd` | راه‌اندازی صحنه، دوربین، ورودی و حلقه‌ی اصلی |

## تست خودکار

```
godot --headless --path . -- --smoke
```

این دستور بازی را بدون پنجره اجرا می‌کند، خرید، دزدی، فروشگاه، هر ۵ دنیا و ذخیره را امتحان می‌کند و نتیجه را چاپ می‌کند.
