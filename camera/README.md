# Camera

برنامه‌ی **Camera** با **دوربین واقعی همین گوشی یا تبلت** کار می‌کند (از طریق مرورگر). دستگاه شبیه‌سازی‌شده یا تصویر ساختگی ندارد. تصویری که می‌بینی همان تصویر زنده‌ی دوربین دستگاه خودت است و لازم نیست برنامه‌ی دوربین خود دستگاه را باز کنی.

## امکانات

| بخش | توضیح |
| --- | --- |
| اجازه دسترسی | وقتی برنامه را باز کنی **فقط اجازه دوربین** خواسته می‌شود. میکروفون فقط وقتی خودت دکمه‌ی میکروفون را بزنی درخواست می‌شود. |
| تصویر زنده | تصویر دوربین داخل خود برنامه نشان داده می‌شود. |
| زوم ۲۵۰× | دوربین پشت تا **۲۵۰ برابر** و دوربین جلو تا **۲۰ برابر**. با دو انگشت، نوار زوم یا دکمه‌های آماده (۱×، ۲×، ۵×، ۱۰×، ۲۵×، ۵۰×، ۱۰۰×، ۲۵۰×). |
| کیفیت 4K | عکس و ویدیو با بیشترین کیفیتی که دوربین در مرورگر می‌دهد (تا 3840×2160). دکمه‌ی 4K / 1080p / 720p بالای صفحه. |
| دوربین جلو/عقب | دکمه‌ی چرخش پایین صفحه. |
| ویدیو + صدا | دکمه‌ی میکروفون را روشن کن و دکمه‌ی قرمز را بزن. |
| ویدیو سریع | تایم‌لپس: هر ۰٫۵ تا ۱۰ ثانیه یک فریم (۱۵ تا ۳۰۰ برابر سریع‌تر). |
| ویدیو آهسته | اسلوموشن ۲×، ۴× یا ۸× آهسته‌تر. |
| خاموش کردن صفحه | هنگام ضبط، صفحه کاملاً سیاه می‌شود ولی ضبط ادامه دارد. دو بار ضربه بزن تا برگردد. |
| بهبود کیفیت عکس | هر عکسی را وارد کن: حذف نویز، اصلاح نور و رنگ، بزرگ‌کردن ۲× یا ۴× و شفاف‌کردن جزئیات، با مقایسه‌ی قبل و بعد. |
| گالری | همه‌ی عکس‌ها و ویدیوها داخل برنامه ذخیره می‌شوند. «ذخیره در دستگاه» یا «اشتراک‌گذاری» آن‌ها را به گالری گوشی/تبلت می‌برد. |

همه‌ی پردازش‌ها روی خود دستگاه انجام می‌شود و هیچ عکس یا ویدیویی جایی فرستاده نمی‌شود.

## چطور روی تبلت/گوشی باز کنم؟

مرورگر فقط روی آدرس امن (https) اجازه‌ی دوربین می‌دهد. ساده‌ترین راه GitHub Pages است (رایگان):

1. در GitHub به مخزن `arezooaa2001-collab/0` برو ← **Settings** ← **Pages**.
2. در قسمت **Build and deployment**، گزینه‌ی **Source** را روی **Deploy from a branch** بگذار.
3. شاخه (Branch) را انتخاب کن (`main`، یا اگر هنوز ادغام نشده `claude/camera-app-250x-zoom-2yz0qy`) و پوشه را `/ (root)` بگذار و **Save** را بزن.
4. بعد از یکی دو دقیقه برنامه در این آدرس باز می‌شود:
   **https://arezooaa2001-collab.github.io/0/camera/**
5. در Chrome اندروید: منوی ⋮ ← «افزودن به صفحه اصلی / نصب برنامه». در Safari آیپد/آیفون: دکمه‌ی اشتراک ← «Add to Home Screen». حالا آیکون **Camera** مثل یک برنامه‌ی معمولی روی دستگاهت است.

برای اجرا روی کامپیوتر: داخل پوشه‌ی اصلی مخزن `python3 -m http.server 8000` را اجرا کن و `http://localhost:8000/camera/` را باز کن.

## محدودیت‌های واقعی (صادقانه)

- **زوم ۲۵۰×:** برنامه اول زوم سخت‌افزاری خود دوربین را تا آخرین حد استفاده می‌کند (لنز تله/سنسور، اگر مرورگر اجازه بدهد) و بقیه‌اش را با زوم دیجیتال پرکیفیت روی پردازنده‌ی گرافیکی انجام می‌دهد (درون‌یابی بای‌کیوبیک + شفاف‌سازی بدون هاله). خروجی 4K است، ولی هیچ برنامه‌ای نمی‌تواند جزئیاتی را که لنز و سنسور اصلاً ثبت نکرده‌اند بسازد؛ برای همین زیر نوار زوم نوشته می‌شود که در آن زوم چند پیکسل واقعی از دوربین روی صفحه است. هرچه زوم بیشتر، تصویر نرم‌تر و لرزش دست بیشتر دیده می‌شود (تبلت را تکیه بده).
- **ضبط با صفحه‌ی خاموش:** اگر دکمه‌ی پاور را بزنی یا دستگاه قفل شود، سیستم‌عامل و مرورگر برای حفظ حریم خصوصی دوربین را قطع می‌کنند (در iPad/iPhone این برای همه‌ی برنامه‌ها همین‌طور است). برای همین دکمه‌ی **«خاموش کردن صفحه»** گذاشته شده: صفحه کاملاً سیاه می‌شود (روی صفحه‌های OLED واقعاً خاموش است) ولی ضبط ادامه دارد، و برنامه نمی‌گذارد صفحه خودبه‌خود خاموش شود. اگر دستگاه قفل شود، هرچه تا آن لحظه ضبط شده خودکار ذخیره می‌شود و ویدیوهای نیمه‌کاره دفعه‌ی بعد که برنامه باز شود بازیابی می‌شوند.
- **ویدیو آهسته:** نرمی آن به تعداد فریمی بستگی دارد که مرورگر از دوربین می‌گیرد (معمولاً ۳۰ تا ۶۰ فریم در ثانیه؛ عدد واقعی بالای صفحه نوشته می‌شود). فریم‌های بین آن‌ها با ترکیب فریم‌های کناری ساخته می‌شوند.
- **ویدیوی سریع و آهسته** بدون صدا ساخته می‌شوند.
- **بهبود کیفیت عکس** با الگوریتم‌های پردازش تصویر روی خود دستگاه انجام می‌شود؛ نویز را کم می‌کند، رنگ و نور را درست می‌کند و لبه‌ها را شفاف می‌کند، ولی جزئیات خیالی نمی‌سازد. در آیپد/آیفون اندازه‌ی خروجی حداکثر حدود ۱۶ مگاپیکسل است (محدودیت مرورگر).
- مرورگر پیشنهادی: Chrome به‌روز (اندروید) یا Safari به‌روز (آیپد/آیفون، iPadOS 16.4 به بعد).

## ساختار فایل‌ها

```
camera/
  index.html            صفحه‌ها (اجازه، دوربین، گالری، نمایشگر، بهبود عکس)
  css/style.css
  js/app.js             دوربین، زوم، عکس، ضبط ویدیو، حالت‌های سریع/آهسته، گالری
  js/renderer.js        زوم دیجیتال روی GPU (WebGL)
  js/encoder.js         ساخت MP4 برای ویدیوی سریع/آهسته (WebCodecs)
  js/storage.js         گالری و ذخیره‌ی امن ضبط در حافظه‌ی دستگاه (IndexedDB)
  js/enhancer.js        صفحه‌ی بهبود کیفیت عکس
  js/enhance-core.js    موتور بهبود عکس (در Web Worker)
  vendor/mp4-muxer.js   کتابخانه‌ی mp4-muxer (MIT)
  sw.js, manifest.webmanifest, icons/   نصب به‌عنوان برنامه و کار آفلاین
```
