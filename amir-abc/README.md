# AMIR ABC

| فایل | توضیح |
|---|---|
| `AMIR_ABC.html` | سایت کامل در یک فایل (تصویر، فونت وزیرمتن، CSS و JS داخل خود فایل؛ آفلاین کار می‌کند) |
| `AMIR_ABC.apk` | اپ اندروید (`com.amirabc.official`، نسخه 1.3، حداقل Android 8.0) |
| `android/` | پروژه استاندارد اندروید (قابل باز کردن در Android Studio) |
| `src/template.html` | سورس صفحه؛ `build_html.py` آن را به `AMIR_ABC.html` تبدیل می‌کند |

## صفحه رنگ سایت

با زدن روی لوگو، صفحه «رنگ سایت» باز می‌شود (تم پیش‌فرض: رنگین‌کمان متحرک؛ صدای برنامه: پیش‌فرض یا بدون صدا؛ انتخاب لوگو: لوگوی جدید AMIR ABC یا لوگوی قبلی AMIR BAKHTIARI، رنگین‌کمانی یا تک‌رنگ، ۶ نوع رنگین‌کمان، ۸ رنگ آماده، ۲ تا ۷ رنگ دلخواه، حرکت رنگ‌ها). انتخاب روی همان دستگاه ذخیره می‌شود.

## ویدیوهای محبوب

زیر دکمه اینستاگرام، دکمه «دیدن ۳ ویدیوی محبوب»؛ زدن روی هر ویدیو مستقیم آن ویدیو را در پیج AMIR ABC در اینستاگرام باز می‌کند (در اپ اندروید داخل خود برنامه، در مرورگر در زبانه جدید).

## دیدن کامل پیج

دکمه «دیدن کامل پیج AMIR ABC»: در اپ اندروید، پیج را در صفحه اینستاگرامِ داخل خود برنامه (سایت رسمی اینستاگرام) باز می‌کند؛ با ورود به حساب اینستاگرام در همان صفحه، لایک هم ممکن است. در مرورگر، نمایشگر رسمی پروفایل اینستاگرام (embed) نشان داده می‌شود.

## تیکت به ما

دکمه «🎫 تیکت به ما» کنار لوگو صفحه تیکت را باز می‌کند (موضوع، متن، نام و راه تماس اختیاری).

- **حالت فعلی:** با زدن «ارسال تیکت به ما»، برنامه ایمیل کاربر با گیرنده `arezoo.aa2001@gmail.com` و متن تیکت باز می‌شود و کاربر دکمه Send را می‌زند (ایمیل واقعی از حساب خودش).
- **ارسال خودکار (بدون برنامه ایمیل):** یک کلید رایگان از web3forms.com برای همین ایمیل بگیرید و در `src/template.html` مقدار `WEB3FORMS_KEY` را بگذارید، بعد `./build_apk.sh` را اجرا کنید. پیام «ارسال شد» فقط وقتی نشان داده می‌شود که سرویس ارسال را تأیید کند؛ اگر نشد، راه برنامه ایمیل پیشنهاد می‌شود.

## ساخت دوباره

```bash
python3 build_html.py      # فقط HTML
./build_apk.sh             # HTML + APK  (نیاز: apt install aapt apksigner android-sdk-platform-23 dalvik-exchange zipalign)
python3 make_icons.py      # ساخت دوباره آیکون‌ها
```

یا پوشه `android/` را در Android Studio باز کنید (قبلش `AMIR_ABC.html` را در `android/app/src/main/assets/` کپی کنید؛ اسکریپت این کار را خودش انجام می‌دهد).

کلید امضای APK در `android/keystore/` ساخته می‌شود و عمداً در git نیست.
اگر با کلید دیگری بسازید، برای نصب نسخه جدید باید نسخه قبلی را پاک کنید.

فونت‌ها: Vazirmatn و Cinzel Decorative (هر دو با مجوز OFL؛ فایل‌های `assets/*-OFL.txt`).
