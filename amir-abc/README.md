# AMIR ABC

| فایل | توضیح |
|---|---|
| `AMIR_ABC.html` | سایت کامل در یک فایل (تصویر، فونت وزیرمتن، CSS و JS داخل خود فایل؛ آفلاین کار می‌کند) |
| `AMIR_ABC.apk` | اپ اندروید (`com.amirabc.official`، نسخه 1.2، حداقل Android 8.0) |
| `android/` | پروژه استاندارد اندروید (قابل باز کردن در Android Studio) |
| `src/template.html` | سورس صفحه؛ `build_html.py` آن را به `AMIR_ABC.html` تبدیل می‌کند |

## صفحه رنگ سایت

با زدن روی لوگو، صفحه «رنگ سایت» باز می‌شود (انتخاب لوگو: لوگوی جدید AMIR ABC یا لوگوی قبلی AMIR BAKHTIARI، رنگین‌کمانی یا تک‌رنگ، ۶ نوع رنگین‌کمان، ۸ رنگ آماده، ۲ تا ۷ رنگ دلخواه، حرکت رنگ‌ها). انتخاب روی همان دستگاه ذخیره می‌شود.

## ویدیوهای محبوب

زیر دکمه اینستاگرام، دکمه «دیدن ۳ ویدیوی محبوب» سه ریل را با پخش‌کننده رسمی اینستاگرام (embed) داخل صفحه پخش می‌کند؛ هر ویدیو دکمه «دیدن در اینستاگرام» هم دارد. پخش به اینترنت نیاز دارد.

## دیدن کامل پیج

دکمه «دیدن کامل پیج AMIR ABC»: در اپ اندروید، پیج را در صفحه اینستاگرامِ داخل خود برنامه (سایت رسمی اینستاگرام) باز می‌کند؛ با ورود به حساب اینستاگرام در همان صفحه، لایک هم ممکن است. در مرورگر، نمایشگر رسمی پروفایل اینستاگرام (embed) نشان داده می‌شود.

## ساخت دوباره

```bash
python3 build_html.py      # فقط HTML
./build_apk.sh             # HTML + APK  (نیاز: apt install aapt apksigner android-sdk-platform-23 dalvik-exchange zipalign)
python3 make_icons.py      # ساخت دوباره آیکون‌ها
```

یا پوشه `android/` را در Android Studio باز کنید (قبلش `AMIR_ABC.html` را در `android/app/src/main/assets/` کپی کنید؛ اسکریپت این کار را خودش انجام می‌دهد).

کلید امضای APK در `android/keystore/` ساخته می‌شود و عمداً در git نیست.
اگر با کلید دیگری بسازید، برای نصب نسخه جدید باید نسخه قبلی را پاک کنید.

فونت‌ها: Vazirmatn و Cinzel Decorative (هر دو با مجوز OFL؛ فایل‌های `assets/*-OFL.txt`).
