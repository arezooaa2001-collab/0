# واژه‌دان

کتابخانهٔ شخصی کلمه‌ها به ۱۶۹ زبان، با دکمهٔ بلندگو برای شنیدن تلفظ و دستیار هوش مصنوعی برای یادگیری.

## دو نسخه

| | `index.html` (داخل Claude) | `vazhedan.html` (هر مرورگری) |
|---|---|---|
| فضای ابری | پایگاه‌دادهٔ Claude، خودکار | یک Gist خصوصی در حساب GitHub خودت (با کلید gist) |
| دستیار هوش مصنوعی | Claude، بدون کلید | Gemini با کلید API، یا مدل داخل مرورگر بدون کلید (WebLLM) |
| صدا | صداهای دستگاه | صداهای دستگاه + صدای آنلاین برای زبان‌هایی که صدایشان نصب نیست |

- نسخهٔ آنلاین: https://claude.ai/artifact/BfqWwnBHJFotrq2KzF22AT
- `vazhedan.html` را با دوبار کلیک در Chrome، Edge یا Safari باز کن. برای فضای ابری، در بخش «فضای ابری» کلید GitHub را وارد کن (لینک ساخت کلید داخل برنامه هست). روی هر دستگاهی همان کلید را وارد کنی، همان کتابخانه را می‌بینی.
- کلیدها (GitHub و Gemini) فقط در حافظهٔ همان مرورگر نگه داشته می‌شوند.
