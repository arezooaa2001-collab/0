# واژه‌دان

کتابخانهٔ شخصی کلمه‌ها به هر زبانی، با دکمهٔ بلندگو برای شنیدن تلفظ.

- **نسخهٔ آنلاین (با فضای ابری):** https://claude.ai/artifact/BfqWwnBHJFotrq2KzF22AT
  کلمه‌ها در پایگاه‌دادهٔ ابری همین صفحه، در بخش خصوصیِ حساب هر نفر ذخیره می‌شوند و روی هر دستگاهی که با همان حساب وارد شوی در دسترس‌اند.
- **اجرای مستقل:** اگر `index.html` را بیرون از Claude باز کنی، کلمه‌ها فقط روی همان مرورگر (localStorage) ذخیره می‌شوند.
- **صدا:** پخش با Web Speech API مرورگر انجام می‌شود؛ کیفیت و زبان‌های در دسترس به صداهای نصب‌شده روی دستگاه بستگی دارد.
