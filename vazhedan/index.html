کلمه یا متن تازه

کتابخانه

    در حال باز کردن کتابخانه… کلمه‌های ذخیره‌شده‌ات اینجا با یک دکمهٔ بلندگو نشان داده می‌شوند.

    دستیار زبان

    هر کلمه‌ای خواستی بپرس تا معنی، تلفظ و مثالش را یاد بگیری، یا از کلمه‌های کتابخانه‌ات امتحان بگیرد. کلمه‌هایی که یاد می‌دهد دکمهٔ پخش و ذخیره دارند.

    تنظیم کلید Gemini
    1. به aistudio.google.com/apikey برو و با حساب گوگل وارد شو.
    2. دکمهٔ Create API key را بزن و کلید را کپی کن.
    3. کلید را اینجا بگذار و «ذخیره و آزمایش» را بزن.

    کلید فقط روی همین دستگاه نگه داشته می‌شود و فقط برای گوگل فرستاده می‌شود.

    تنظیم هوش مصنوعی بدون کلید

    این دستیار یک مدل هوش مصنوعی کوچک است که داخل خود مرورگرت اجرا می‌شود. کلید و حساب نمی‌خواهد و حرف‌هایت از دستگاهت بیرون نمی‌رود. بار اول مدل دانلود می‌شود و بعد از آن بدون دانلود دوباره کار می‌کند.

    به Chrome یا Edge جدید با پشتیبانی WebGPU نیاز دارد (کامپیوتر، یا گوشی اندرویدی قوی). مدل کوچک گاهی اشتباه می‌کند؛ برای جواب‌های دقیق‌تر Gemini را انتخاب کن.

    فضای ابری فعال است

    کتابخانه‌ات در فضای ابری حساب Claude تو ذخیره می‌شود. صفحه را ببندی، رفرش کنی یا سال‌ها بعد برگردی، کلمه‌ها سر جایشان هستند. روی هر دستگاهی که با همین حساب این صفحه را باز کنی، همین کتابخانه را می‌بینی.

    نسخهٔ فایل HTML (بیرون از Claude) فضای ابری جداگانه‌ای دارد که با GitHub کار می‌کند.

    اتصال به فضای ابری

    کتابخانه در یک فایل خصوصی در حساب GitHub خودت ذخیره می‌شود. GitHub رایگان است و فایل برای همیشه می‌ماند. هر وقت و روی هر دستگاهی همین برنامه را باز کنی و همین کلید را وارد کنی، کلمه‌هایت را می‌بینی.

    1. اگر حساب GitHub نداری، رایگان بساز: github.com/signup
    2. این لینک را باز کن تا کلید مخصوص ساخته شود: ساخت کلید GitHub
    3. در بخش Expiration گزینهٔ No expiration را انتخاب کن تا کلید هیچ‌وقت باطل نشود. تیک gist خودش زده شده است.
    4. پایین صفحه Generate token را بزن، کلیدی را که با ghp_ شروع می‌شود کپی کن و اینجا بگذار.

    کلید را به کسی نده. فقط روی همین دستگاه نگه داشته می‌شود و فقط به GitHub فرستاده می‌شود.

    دیدن فایل ابری

    روی دستگاه دیگر، همین برنامه را باز کن و در همین بخش همان کلید را وارد کن. قطع اتصال فقط این دستگاه را جدا می‌کند و چیزی از فضای ابری پاک نمی‌شود.

    فضای ابری

    این صفحه داخل Claude باز شده ولی به حساب Claude وصل نیست. وارد حسابت شو تا کتابخانه در فضای ابری ذخیره شود.
