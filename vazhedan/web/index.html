راه‌اندازی یک‌بارهٔ ورود با گوگل

برای اینکه ورود با حساب واقعی گوگل و فضای ابری کار کند، برنامه به یک پروژهٔ رایگان Firebase (سرویس گوگل) وصل می‌شود. این کار فقط یک بار لازم است.

  1. به console.firebase.google.com برو، با حساب گوگلت وارد شو و Create a project را بزن. یک اسم بده (مثلاً vazhedan) و مراحل را تا آخر جلو برو.
  2. از منوی سمت چپ Security (یا Build) ← Authentication ← Get started. در بخش Sign-in method، گزینهٔ Google را انتخاب کن، Enable را روشن کن و Save بزن.
  3. در همان Authentication، به Settings ← Authorized domains برو، Add domain را بزن و این را اضافه کن:
  4. Databases & Storage (یا Build) ← Firestore Database ← Create database. حالت Production را انتخاب کن و یک منطقه (location) بردار.
  5. در Firestore به تب Rules برو، همه‌چیز را پاک کن، این را بگذار و Publish بزن. با این قانون هر کس فقط کلمه‌های خودش را می‌بیند:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid}/{document=**} { allow read, write: if request.auth != null && request.auth.uid == uid; } } }
  6. برای دستیار رایگان بدون کلید: AI ← AI Logic ← Get started و گزینهٔ Gemini Developer API را فعال کن.
  7. روی چرخ‌دندهٔ ⚙️ ← Project settings بزن. پایین صفحه در Your apps روی آیکن وب </> بزن، یک اسم بده و Register app را بزن.
  8. بخشی را که با const firebaseConfig = { شروع می‌شود کپی کن، اینجا بگذار و «ذخیره» را بزن.

این تنظیمات رمز نیستند و فقط آدرس پروژهٔ تو را مشخص می‌کنند.

به واژه‌دان خوش آمدی

با حساب گوگل خودت وارد شو. کتابخانه‌ات در فضای ابری همین حساب ذخیره می‌شود و روی هر دستگاهی که وارد شوی، همان را می‌بینی.

کلمه یا متن تازه

کتابخانه

    در حال باز کردن کتابخانه… کلمه‌های ذخیره‌شده‌ات اینجا با یک دکمهٔ بلندگو نشان داده می‌شوند.

    دستیار زبان

    هر کلمه‌ای خواستی بپرس تا معنی، تلفظ و مثالش را یاد بگیری، یا از کلمه‌های کتابخانه‌ات امتحان بگیرد. کلمه‌هایی که یاد می‌دهد دکمهٔ پخش و ذخیره دارند.

    تنظیم کلید Gemini
    1. به aistudio.google.com/apikey برو و با حساب گوگل وارد شو.
    2. دکمهٔ Create API key را بزن و کلید را کپی کن.
    3. کلید را اینجا بگذار و «ذخیره و آزمایش» را بزن.

    کلید فقط روی همین دستگاه نگه داشته می‌شود و فقط برای گوگل فرستاده می‌شود. با این کلید، کلمه‌هایی که صدایشان روی دستگاه نیست با صدای Gemini هم پخش می‌شوند.

    حساب من

    کتابخانه‌ات در فضای ابری و به نام همین حساب گوگل ذخیره می‌شود. صفحه را ببندی، رفرش کنی یا سال‌ها بعد برگردی، کلمه‌ها سر جایشان هستند. روی هر گوشی یا کامپیوتری با همین حساب وارد شوی، همین کتابخانه را می‌بینی. اگر اینترنت قطع باشد، کلمه‌ها روی دستگاه می‌مانند و وقتی وصل شدی خودشان به ابر می‌روند.
