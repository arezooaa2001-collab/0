# 🏁 شتاب — شبیه‌ساز مسابقه‌ی اتومبیلرانی سه‌بعدی

بازی مسابقه‌ای کامل که مستقیم داخل مرورگر (موبایل و کامپیوتر) اجرا می‌شود؛ بدون نصب و بدون هیچ فایل تصویری یا صوتی — همه‌ی مدل‌ها، بافت‌ها و صداها به‌صورت پردازشی ساخته می‌شوند.

## اجرا

```bash
cd racing
python3 -m http.server 4180      # یا: npm start
# سپس در مرورگر:  http://localhost:4180
```

> نسخه‌ی پوشه‌ای از ES Module استفاده می‌کند و باید از طریق یک وب‌سرور اجرا شود. روی GitHub Pages هم بدون تغییر کار می‌کند.

### نسخه‌ی تک‌فایلی (بدون نیاز به سرور)

فایل **`dist/shetab-racing.html`** کل بازی (کد، استایل و three.js) را در یک فایل HTML دارد؛ کافی است روی آن دوبار کلیک کنید یا آن را روی گوشی باز کنید.
برای ساخت دوباره‌ی آن بعد از تغییر کد:

```bash
npm install            # فقط بار اول (esbuild)
npm run build:single   # خروجی: dist/shetab-racing.html
```

## ویژگی‌ها

### مسابقه و پیشرفت
- **۲۰ ماشین در هر مسابقه** (شما + ۱۹ راننده‌ی هوش مصنوعی) که دقیقاً با همان فیزیک ماشین شما رانندگی می‌کنند، سبقت می‌گیرند، از برخورد دوری می‌کنند و گاهی اشتباه می‌کنند.
- **۳۰ مرحله** در ۶ محیط: چمنزار، کویر، ساحل، جنگل غروب، کوهستان برفی و شهر در شب — با آب‌وهوای آفتابی، بارانی، برفی و مه.
- **پاداش سکه بر اساس رتبه در هر مرحله:**

  | رتبه | ۱ | ۲ | ۳ | ۴ | ۵ | ۶ به بعد |
  |---|---|---|---|---|---|---|
  | سکه | ۱۰۰ | ۵۰ | ۱۰ | ۵ | ۲ | ۰ |

- **امتیاز (⭐)** برای هر مسابقه (۲۵، ۱۸، ۱۵، ...) و **سطح بازیکن** که با امتیاز بالا می‌رود.
- با رسیدن به سکو (رتبه‌ی ۱ تا ۳) مرحله‌ی بعد باز می‌شود. سختی رقبا مرحله به مرحله بیشتر می‌شود.
- پیشرفت بازی به‌صورت خودکار ذخیره می‌شود.

### گاراژ و ارتقا
- **۷ ماشین** با مشخصات واقعی متفاوت (دیفرانسیل جلو/عقب/چهارچرخ، قدرت، وزن، آیرودینامیک): شاهین، توفان، تندر، شبدیز، آذرخش، سیمرغ، رخش.
- **۵ ارتقا** برای هر ماشین، هر کدام تا ۵ سطح: موتور، نیترو، لاستیک، ترمز، تعلیق و آیرودینامیک.
- تغییر رنگ (۱۶ رنگ + رنگ دلخواه) و نمایش سه‌بعدی ماشین روی صفحه‌ی چرخان.

### ۲۶ سطح گرافیک
کم، متوسط، خوب، خیلی خوب، فوق‌العاده، **اولترا مکس** و **۲۰ سطح بالاتر از اولترا مکس** (اولترا مکس پلاس، هایپر، اکستریم، سینمایی، فوتورئال، تایتان، کوانتوم، نوا، افسانه، بی‌نهایت، امگا، واقعیت مطلق و ...).

هر سطح بالاتر هم **جزئیات تصویر** را بیشتر می‌کند (رزولوشن و سوپرسمپلینگ، سایه تا ۸K، ضدلبه MSAA، درخشش نور، بازتاب زنده روی بدنه، محو حرکتی، AO، علف تا ۳۲۰ هزار برگ، درخت و تماشاگر بیشتر، بافت ۴K، ذرات بیشتر و ...) و هم **رفتار بازی را واقعی‌تر** می‌کند (فیزیک دقیق‌تر از ۱۲۰ تا ۱۲۰۰ هرتز، حرکت بدنه و تعلیق، مکش پشت ماشین‌ها، مدل لاستیک وابسته به بار، تأخیر تعویض دنده، دست‌انداز جاده، آسیب‌دیدگی بدنه، دمای لاستیک و آیرودینامیک هوای آشفته).

### کنترل لمسی طبیعی (موبایل)
- **کشیدن آنالوگ** (پیش‌فرض): هر جای نیمه‌ی چپ صفحه را لمس و چپ/راست بکشید؛ مرکز فرمان همراه انگشت جابه‌جا می‌شود.
- **فرمان مجازی** که با انگشت می‌چرخد و خودش به وسط برمی‌گردد.
- **دکمه‌های چپ/راست** و **شیب گوشی (ژیروسکوپ)**.
- پدال گاز و ترمز با امکان لغزاندن انگشت بین آن‌ها، نیترو و ترمز دستی، چندلمسی کامل، لرزش (هپتیک)، تنظیم حساسیت، اندازه‌ی دکمه‌ها، جای پدال‌ها و گاز خودکار.
- فرمان وابسته به سرعت و کمک راننده (ABS، کنترل کشش و پایداری) در سه سطح.

کیبورد: جهت‌ها یا WASD، Space ترمز دستی، Shift نیترو، C دوربین، B نگاه به عقب، R بازگشت به مسیر، P توقف. دسته‌ی بازی (Gamepad) هم پشتیبانی می‌شود.

## ساختار کد

```
racing/
  index.html            صفحه و منوها
  css/game.css          ظاهر (راست‌به‌چپ، واکنش‌گرا)
  js/core/              تنظیمات بازی (ماشین‌ها، ارتقاها، مراحل، پاداش‌ها)، ذخیره‌سازی، ابزارها
  js/game/              پیست‌ساز، فیزیک خودرو، هوش مصنوعی، مدیریت مسابقه، دوربین، ورودی‌ها
  js/gfx/               رندرر و پس‌پردازش، سطوح گرافیک، بافت‌ها، مدل ماشین‌ها، محیط، جلوه‌ها
  js/audio/             صدای موتور و جلوه‌ها (WebAudio)
  js/ui/                منوها، گاراژ سه‌بعدی، HUD
  vendor/three/         three.js r170 (محلی، بدون نیاز به CDN)
  tests/                تست‌های شبیه‌سازی (Node) و تست‌های مرورگر (Playwright)
```

## تست

```bash
npm test                          # پیست‌ها، فیزیک، هوش مصنوعی، پاداش‌ها و تعادل سختی
npm start &  npm run test:e2e     # مسابقه‌ی کامل، گاراژ، هر ۲۶ سطح گرافیک، کنترل لمسی، منوی توقف
```

---

**Shetab** is a browser racing simulator (three.js, no build step): 20-car races, 30 procedurally generated circuits, garage with 7 cars and 5 upgrade paths, rank-based coin rewards (100/50/10/5/2/0), 26 graphics presets (6 named + 20 beyond Ultra Max, each also raising simulation realism) and natural multi-touch mobile controls.
