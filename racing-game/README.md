# قهرمان پیست 🏁

بازی مسابقه‌ای سه‌بعدی فارسی که کامل داخل مرورگر اجرا می‌شود (Three.js، بدون نصب).

## اجرا

```bash
cd racing-game
python3 -m http.server 8080
# سپس در مرورگر باز کن: http://localhost:8080
```

فایل‌ها باید از طریق یک سرور ساده باز شوند (نه با دوبار کلیک روی فایل)، چون بازی از ماژول‌های جاوااسکریپت استفاده می‌کند. Three.js و فونت وزیرمتن از اینترنت (CDN) بارگذاری می‌شوند.

## فایل HTML تکی (بدون اینترنت)

`dist/ghahreman-pist.html` یک فایل کامل است: Three.js، کد بازی، CSS و فونت وزیرمتن داخل خودش است و با دوبار کلیک در مرورگر (کروم، فایرفاکس، اج، سافاری) بدون اینترنت اجرا می‌شود.

ساخت دوباره:

```bash
cd racing-game
npm install
npm run build:html
```

## نسخه اندروید (APK)

پوشه `android/` یک برنامه اندروید ساده است که بازی را در یک WebView تمام‌صفحه و افقی اجرا می‌کند (دکمه برگشت گوشی هم کار می‌کند).

ساخت روی کامپیوتر خودت (نیاز به JDK 17 و Android SDK با build-tools و یک platform):

```bash
cd racing-game
npm install
npm run build:html
ANDROID_HOME=$HOME/Android/Sdk npm run build:apk   # خروجی: dist/ghahreman-pist.apk
```

یا در گیت‌هاب: تب **Actions** ← **Build Ghahreman Pist APK** ← **Run workflow**. بعد از پایان، فایل APK و HTML در بخش Artifacts همان اجرا قابل دانلود است.

برای اینکه نسخه‌های بعدی روی نسخه قبلی نصب شوند، همیشه با یک کلید ثابت امضا کن (`KEYSTORE_FILE`، `KEYSTORE_PASS`، `KEY_ALIAS`).

## امکانات

- **منوی اصلی**: شروع بازی، خرید و دیدن ماشین، شخصی‌سازی ماشین، تنظیمات، تنظیم نور بازی
- **۱۰۰۰ مرحله** با پیست‌های واقعی و طولانی (از حدود ۳٫۴ تا ۷ کیلومتر) که هر مرحله سخت‌تر می‌شود: پیچ‌های تندتر، ارتفاع بیشتر، رقبای قوی‌تر
- پیست واقعی: آسفالت با بافت، خط‌های سفید، کرب قرمز و سفید، شن‌زار و فضای ایمنی، دیوار لاستیکی، گاردریل، دیوار بتنی با تبلیغات و توری، جایگاه تماشاگران با سقف و پرچم، ساختمان پیت، دروازه شروع با چراغ، نمایشگر بزرگ رتبه‌ها، بیلبورد، پل، برج نور، تابلوهای ۳۰۰/۲۰۰/۱۰۰، درخت و کوه
- شمارش معکوس ۳ ثانیه‌ای با چراغ‌های دروازه شروع
- **سکه‌ها**: نفر اول ۱۵۰، دوم ۱۰۰، سوم ۵۰، چهارم ۲۰، پنجم ۱۰، ششم ۵، هفتم ۲. برای باز شدن مرحله بعد باید جزو سه نفر اول باشی
- **۲۰ ماشین** از قدیمی (کلاسیک دهه ۵۰) تا افسانه‌ای. اول فقط ضعیف‌ترین ماشین باز است. ماشین‌ها با سطح تو قابل خرید می‌شوند (از سطح ۲۰ به بعد) و با سکه خریده می‌شوند
- **گاراژ مخصوص**: ماشین‌های قفل زیر پارچه پوشیده‌اند و اسمشان دیده نمی‌شود
- **شخصی‌سازی**: رنگ، نوع رنگ، رینگ، رنگ رینگ، اسپویلر، خط مسابقه، شیشه دودی، نئون، رنگ دود لاستیک، لباس راننده، شماره + ارتقای موتور، توربو، لاستیک، ترمز، کاهش وزن و نیترو
- هر ماشین فقط دو صندلی جلو دارد؛ از پشت شیشه راننده، فرمان، دنده، پدال‌ها و داشبورد دیده می‌شوند
- **سه دید**: سوم شخص، اول شخص (داخل ماشین)، و دید از بالا (۲ متر بالاتر و ۲ متر عقب‌تر)
- **تماشاگران واقعی** با صورت، چشم، بینی، دهان، گوش، مو، دست و انگشت، شکم و پا که تشویق می‌کنند و سرشان ماشین‌ها را دنبال می‌کند. طرفدارهای تو لباس قرمز-نارنجی-زرد دارند و طرفدارهای رقبا رنگ تیم خودشان را
- **رئیس کل پیست** با لباس رنگین‌کمانی متحرک: در مرحله ۵۰۰ و ۱۰۰۰ کنار طرفدارهای تو می‌نشیند و رتبه را فقط بر اساس قدرت، سرعت و ظاهر ماشین داوری می‌کند (۱۰۰۰ با تاج و آتش‌بازی). در مراحل ۱۰۰، ۲۰۰، ۳۰۰، ۴۰۰ (و ۶۰۰ تا ۹۰۰) کنار طرفدارهای رقبا می‌نشیند
- **ویدیوی مسابقه**: بعد از هر مرحله یک بار می‌توانی کل مسابقه را با دوربین‌های تلویزیونی، هلیکوپتر، داخل ماشین و تماشاگران ببینی
- تنظیم نور: زمان روز (صبح، ظهر، غروب، شب)، روشنایی، خورشید، نور محیط، درخشش، مه، ابر، سایه
- **رقبای سخت‌تر**: هر ۲ مرحله رقبا سریع‌تر می‌شوند و ماشینشان هم عوض می‌شود (از کلاسیک‌های قدیمی تا ماشین‌های افسانه‌ای با اسپویلر، نئون و رنگ متالیک)
- **موتورها**: دکمه «موتورها» در منو، گاراژی با ۱۲ موتور (اسکوتر، کلاسیک، چاپر، تریل، کروزر، تورینگ، نیکد، اسپرت، سوپربایک، مسابقه‌ای). همه قفل‌اند و با زدن «استفاده» پیام «به زودی اضافه خواهد شد...» می‌آید؛ بعد از رد کردن ۱۰۰ مرحله یا با کد `157127` همه باز می‌شوند و در مسابقه و شهر آزاد سوارشان می‌شوی
- **شهر آزاد** (تنظیمات ← حالت بازی): یک شهر بزرگ با خیابان، چراغ راهنمایی، ترافیک، عابر پیاده، خانه‌هایی که درشان با نزدیک شدن باز می‌شود و داخلشان مبلمان کامل دارند، برج‌ها و مغازه‌ها، میدان با فواره و مجسمه، زمین پرش با رمپ و یک **شهربازی** (چرخ و فلک، ترن هوایی، چرخ گردون، صندلی پرنده، برج سقوط، ماشین برقی، تاب، سرسره، الاکلنگ، غرفه‌ها). با **دکمه تعامل** از همه چیز استفاده می‌شود: نشستن، خوابیدن، روشن کردن تلویزیون و چراغ، باز کردن یخچال، آب دادن به گلدان، سوار شدن ماشین‌ها و وسایل شهربازی و ...
- **ماموریت‌ها** در شهر آزاد (قابل روشن/خاموش، هر ۵ یا ۱۰ یا ۱۵ دقیقه): نیمی نجات (نجات آدمی که دارد خفه می‌شود با مانور هایملیخ، نجات آدم‌های گیرافتاده در خانه آتش‌گرفته) و نیمی پاکسازی (جمع کردن آشغال‌ها و انداختن در سطل زباله). ماموریت سخت‌تر = سکه بیشتر
- **کنترل لمسی قابل انتخاب** (مسابقه و شهر آزاد): جوی‌استیک (بکش جلو = جلو، عقب = عقب، چپ و راست = فرمان) یا دکمه‌های گاز، ترمز، دنده عقب و دریفت. در مسابقه ترمز دستی نیست؛ دریفت کنترل‌شده جایش را گرفته
- **آب و هوا**: صاف، بارانی و طوفانی با رعد و برق، شتک قطره‌ها و جاده خیس براق
- **جزئیات زنده شهر**: درخت‌هایی که با باد تکان می‌خورند، پرنده‌ها در آسمان، کبوترهای میدان که با نزدیک شدنت پرواز می‌کنند، پروانه‌ها، فواره با جت آب، موج روی آب استخر و فواره، دود دودکش‌ها، تابلوهای تبلیغاتی متحرک روی برج‌ها، راهنمای چشمک‌زن ماشین‌ها، شیشه‌های براق برج‌ها
- **شب‌های زیبا**: نور زیر چراغ‌های خیابان، مخروط نور، پنجره‌های روشن خانه‌ها، نور جلوی ماشین‌ها، آتش‌بازی بالای شهربازی و لامپ‌های رنگین‌کمانی وسایل
- **سرگرمی در شهر**: سکه‌های چرخان برای جمع کردن، سکه طلایی بالای رمپ‌ها، جایزه پرش (بر اساس مدت پرواز و فاصله) و جایزه دریفت، بوق ماشین، رقص و حرکت‌های شاد (دکمه 💃 یا G) که رهگذرها برایش دست می‌زنند
- **سطل‌های زباله واقعی و توخالی**: داخلشان دیده می‌شود و آشغال‌هایی که می‌اندازی داخلشان روی هم جمع می‌شوند
- **انیمیشن نرم‌تر**: تغییر حالت‌های قهرمان (ایستادن، راه رفتن، دویدن، نشستن، ...) بدون پرش، چرخش سر به سمت وسایل، صدای قدم و گرد و خاک دویدن
- **کد مخفی**: در تنظیمات (پس‌زمینه زرد با نقطه‌های نارنجی) پایین‌ترین نقطه کم‌رنگ را بزن
  - `1571`: همه ماشین‌ها باز و خریداری می‌شوند
  - `100200`: همه ماشین‌ها و اسمشان قابل دیدن می‌شوند
  - `157127`: همه موتورها باز می‌شوند
  - `500`: مستقیم به مرحله ۵۰۰ می‌روی

## کنترل‌ها

| کار | صفحه‌کلید | لمسی |
|---|---|---|
| گاز / ترمز | ↑ / ↓ یا W / S | دکمه گاز و ترمز، یا جوی‌استیک (تنظیمات ← کنترل لمسی رانندگی) |
| فرمان | ← → یا A D | دکمه‌های ◀ ▶ |
| دریفت | فاصله | دریفت |
| دنده عقب | ↓ (وقتی ایستاده‌ای) | دنده عقب |
| نیترو | Shift یا N | خودکار در مسیر مستقیم با گاز کامل |
| تغییر دید | C | 🎥 |
| برگشت به پیست | R | ↺ |
| نگاه به اطراف در داخل ماشین | Q / E یا کشیدن موس | کشیدن انگشت |
| توقف | Esc یا P | ❚❚ |

در شهر آزاد: W A S D یا فلش‌ها برای راه رفتن و رانندگی، Shift دویدن/نیترو، فاصله پرش/دریفت، F یا E دکمه تعامل، H بوق، G رقص، C تغییر دید، Y / N قبول یا رد ماموریت. روی گوشی: جوی‌استیک، دکمه پرش، دویدن و دکمه بزرگ تعامل.
