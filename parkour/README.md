# پارکور اوج 🏔️

بازی پارکور سه‌بعدی مرحله‌ای با **۱۰۰۰ مرحله**، **سه حالت مسیر** و **۶ رقیب** که هم‌زمان با تو مسیر را می‌دوند و با تو چت می‌کنند.

## سه راه اجرا

| نسخه | فایل | چت آزاد با هوش مصنوعی |
|---|---|---|
| مرورگر (HTML تک‌فایل، آفلاین) | `dist/index.html` | با وارد کردن کلید API در «تنظیمات ← چت هوشمند» |
| اندروید | `release/OujParkour.apk` | با وارد کردن کلید API در «تنظیمات ← چت هوشمند» |
| داخل Claude | لینک Artifact | بدون کلید؛ بار اول Claude اجازه می‌خواهد |

در هر سه نسخه **۲۰۰ پیام پیشنهادی** (در ۲۰ دسته) همیشه کار می‌کنند و رقبا جواب طبیعی می‌دهند؛ پیام آزاد هم بدون هوش مصنوعی با جواب‌های آماده بر اساس کلمات کلیدی پاسخ می‌گیرد.

## بازی

- **مراحل:** هر بار که مرحله‌ای را شروع می‌کنی، مسیر تازه ساخته می‌شود (هیچ‌وقت تکراری نیست). هرچه جلوتر بروی، فاصله‌ها بیشتر، سکوها کوچک‌تر و موانع سریع‌تر می‌شوند.
- **حالت‌ها** (در منو یا تنظیمات): «رو به جلو» از اول باز است؛ «از بالا به پایین» بعد از مرحلهٔ ۱۰ و «از پایین به بالا» (مارپیچ دور برج غول‌پیکر) بعد از مرحلهٔ ۲۰ باز می‌شوند.
- **موانع:** سکوی متحرک و آسانسور، سکوی فروریزنده، سکوی چشمک‌زن، لیزر، چکش آونگی، بازوی چرخان، سکوی چرخان، پد پرش، دیوار مخصوص دیواردوی، میلهٔ «سُر از زیر»، نوار نقاله، یخ، و پرچم‌های ذخیره (چک‌پوینت).
- **حرکت‌ها:** دویدن، پرش (با نگه داشتن بلندتر)، پرش دوبل با پشتک، سُر خوردن، دیواردوی و پرش از دیوار، بالا رفتن خودکار از لبه.
- **سکه:** بعد از هر مرحله بر اساس شمارهٔ مرحله، رتبه (×۲ برای نفر اول) و سکه‌های جمع‌شده در مسیر.
- **فروشگاه:** سرعت (۱۰ سطح)، پرش (۱۰ سطح)، پرش دوبل، آهنربای سکه، لباس‌های دونده.
- **تنظیمات پولی:** ۸ نورپردازی، نورپردازی سفارشی با اسلایدر، ۱۰ پالت رنگ پارکور و رنگ دلخواه.
- **گرافیک:** سایهٔ نرم، درخشش (bloom)، اصلاح رنگ، خطوط و تاری سرعت، ۱۰ محیط (شهر غروب، شهر نئونی، آسمان صبح، کویر، قله‌های یخی، آتشفشان، فضا، جنگل جادویی، جزیرهٔ استوایی، سایبر سانست)، وضوح پویا برای روان ماندن.

### کنترل‌ها
- **کیبورد:** `W A S D` / جهت‌ها حرکت · `Space` پرش · `Shift` یا `C` سُر · موس دوربین (کلیک برای قفل) · `Enter` چت · `Esc` توقف
- **لمسی:** سمت چپ صفحه جوی‌استیک · دکمهٔ پرش و سُر · کشیدن سمت راست برای دوربین
- **دسته بازی:** استیک‌ها، `A` پرش، `B` سُر، `Start` توقف

## چت هوشمند با کلید API

در نسخهٔ HTML و APK: «تنظیمات ← چت هوشمند» → کلید را از console.anthropic.com وارد کن. کلید فقط روی همان دستگاه ذخیره می‌شود و مستقیم با SDK رسمی Anthropic به `api.anthropic.com` فرستاده می‌شود. مدل پیش‌فرض Claude Opus 5.5 است (Sonnet 5.5 و Haiku 5.5 هم قابل انتخاب‌اند).

## ساخت از سورس

```bash
cd parkour
npm install
npm run build            # → dist/index.html  و  artifact/parkour-ouj.html
bash android/build-apk.sh # → release/OujParkour.apk  (جزئیات: android/README.md)
```

با هر push روی `parkour/**`، گردش‌کار `.github/workflows/parkour-apk.yml` هم APK را می‌سازد.

## ساختار کد (`src/`)

| فایل | کار |
|---|---|
| `level.js` | تولید رویه‌ای مسیر و سختی ۱۰۰۰ مرحله در سه حالت |
| `course.js` | ساخت سه‌بعدی سکوها، موانع، سکه‌ها، پرچم‌ها و برخورددهنده‌ها |
| `player.js` | فیزیک و کنترل بازیکن |
| `character.js` | شخصیت اسکلت‌دار و انیمیشن رویه‌ای (دویدن، پرش، پشتک، سُر، دیواردوی، …) |
| `bots.js` | رقبای کامپیوتری که مسیر را با زمان‌بندی واقعی طی می‌کنند |
| `world.js`, `sky.js` | آسمان، زمین شیدری، مناظر، آب‌وهوا، نور و سایه |
| `game.js` | حلقهٔ اصلی، پس‌پردازش، وضعیت‌ها، پاداش‌ها |
| `chat.js`, `chat-data.js`, `ai.js` | چت، ۲۰۰ پیام پیشنهادی، اتصال به Claude |
| `ui.js`, `template.html`, `styles.css` | منوها، فروشگاه، تنظیمات، HUD |
| `audio.js` | افکت‌ها و موسیقی ساخته‌شده با WebAudio |
